# Stride

A world map of geotagged photos you can walk through. Where several photos
show the same place, Stride aligns them in 3D, so you can step from one photo
to the next in the direction you choose, and later slide through the years.

Panoramio's map and community, Photosynth's walk-through, plus time.

## Key features

- **Map:** photos as pins; aligned clusters marked as explorable places.
- **Capture app:** records GPS, compass heading and tilt with every shot.
- **Alignment:** nearby photos with matching features placed in one 3D space.
- **Walk-through:** swipe or tap to move to the neighbouring photo.
- **Fill the gaps:** shows missing angles and guides you to shoot them.
- **Time slider** and **community** in v2.
- **Privacy:** faces and licence plates blurred automatically.
